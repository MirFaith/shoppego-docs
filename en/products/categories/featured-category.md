# Featured Category

{% hint style="info" %}
\*\*<mark style="color:red;">**Note**</mark>: **Featured category** is a function where **only specified products** will be **displayed on the homepage.**
{% endhint %}

You **do not need** to create this **Featured Category,** as this function is **already available** for continued use.

## Set Featured categories in Preferences

Go to **Online store** -> **Preferences**

![](../../../.gitbook/assets/-MSX-UhgEHTdJ1qDm2nK.png)

In the **Featured category** column, make sure the Featured selection is made by clicking on the category. Featured is already available and can be selected directly.

![](../../../.gitbook/assets/-MSX02cF0EY5DNltng50.png)

Next, click the **Save** button on your homepage and the category display that has been set will appear.

![](../../../.gitbook/assets/-MBca-1GQkVOlIUxL1er.png)
