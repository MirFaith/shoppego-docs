# Settings

The Settings section on Payment options is a setting to allow only **selected countries** to use the payment.

{% hint style="info" %}
**These features can only be used on physical and special products for the&#x20;**<mark style="color:red;">**Ultimate plan**</mark>**&#x20;only.**
{% endhint %}

1\. Log in to the Shoppego dashboard

![](../../../../.gitbook/assets/lCN7aw3FznaFFoOAyya2.jpg)

2\. Click on **Settings**

![](../../../../.gitbook/assets/VsK9zs6aZtUfKK1hcCiM.jpg)

3\. Click on **Payment options**

![](../../../../.gitbook/assets/CA5qmbxGnMXdjUXh5W4M.jpg)

4\. Select any payment gateway or payment system option to which you want to add this setting by clicking on the **Edit** button in their column. For this tutorial we use **SecurePay**.

![](../../../../.gitbook/assets/Abbvn4wQZFKv0vkxWFoT.jpg)

5\. Click on **Settings**

![](../../../../.gitbook/assets/eR7gQUw4pU5FAFjF7aQ7.jpg)

6\. Select the **country where you want to allow the payment to be used** and click **Save**

![](../../../../.gitbook/assets/LESxoWauOrNH6XNWTMmh.jpg)
