# Downloads

Untuk lakukan pengurusan fail export orders, anda boleh pergi pada bahagian:

1. Log masuk akaun Shoppego

<figure><img src="../../.gitbook/assets/lCN7aw3FznaFFoOAyya2.jpg" alt=""><figcaption></figcaption></figure>

2. Klik pada **Files**

<figure><img src="../../.gitbook/assets/4vjY7kr0vHb8lhe6wG2p.jpg" alt=""><figcaption></figcaption></figure>

3. Klik pada tab **Downloads**

<figure><img src="../../.gitbook/assets/e40xp0rJyAjpTenlRJu7.jpg" alt=""><figcaption></figcaption></figure>

4. Seterusnya, anda akan dapat lihat status fail export order anda

<figure><img src="../../.gitbook/assets/Q8zgxsXq0Yen605GfSyO.jpg" alt=""><figcaption></figcaption></figure>

Sekiranya, fail itu sudah boleh di download(Status berubah jadi Completed), anda boleh klik pada butang **download**

{% hint style="info" %}
Perlu dimaklumkan, sekiranya fail export anda itu terlalu besar, perubahan status kepada "Completed" itu akan ambil masa sedikit(bergantung kepada saiz fail anda).
{% endhint %}

<figure><img src="../../.gitbook/assets/WQlzo7S0jpJWllhFxrWp.jpg" alt=""><figcaption></figcaption></figure>

Untuk delete, mana-mana fail export itu, anda boleh klik pada butang **ikon tong sampah**

<figure><img src="../../.gitbook/assets/oHUSCqJpUSDvaNiRigfH.jpg" alt=""><figcaption></figcaption></figure>
