# Files

Untuk lakukan pengurusan fail image yang anda sudah upload didalam editor page, anda boleh pergi pada bahagian:

1. Log masuk akaun Shoppego

<figure><img src="../../.gitbook/assets/lCN7aw3FznaFFoOAyya2.jpg" alt=""><figcaption></figcaption></figure>

2. Klik pada **Files**

<figure><img src="../../.gitbook/assets/4vjY7kr0vHb8lhe6wG2p.jpg" alt=""><figcaption></figcaption></figure>

3. Seterusnya anda akan dapat lihat kesemua fail image yang anda sudah upload didalam editor page anda.

<figure><img src="../../.gitbook/assets/AjvoxhuNJuWtAAKNk9Pi.jpg" alt=""><figcaption></figcaption></figure>

Didalam halaman itu nanti, anda akan dapat lihat maklumat fail-fail image anda.

| Parameter  | Penerangan                                                                        |
| ---------- | --------------------------------------------------------------------------------- |
| Image      | Paparan gambar yang anda telah upload.                                            |
| File Name  | Nama fail yang anda telah upload.                                                 |
| Date Added | Tarikh anda upload fail tersebut.                                                 |
| Size       | Saiz fail yang anda telah upload.                                                 |
| Reference  | Maklumat, anda upload fail itu di sama ada di editor builder atau editor WYSIWYG. |
| Action     | Penetapan yang anda boleh lakukan untuk fail itu.                                 |

Untuk delete mana-mana fail yang anda sudah tidak inginkan, anda boleh klik pada **ikon tong sampah**
