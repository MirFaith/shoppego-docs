# Google Tag Manager

{% hint style="info" %}
**Google tag manager (GTM)** adalah satu alat yang membolehkan **segala aktiviti di dalam website** kita **dikesan bagi tujuan pengumpulan data** supaya penambahbaikan dapat dilakukan.&#x20;
{% endhint %}

Untuk pengetahuan semua, **Google Tag Manager** boleh mengandungi pelbagai **Tracking Tools** contohnya seperti :

* **Facebook Pixel**
* **Google Analytic**
* **Google Search Console** dan **lain-lain.**&#x20;

Terdapat beberapa langkah untuk **integrate Google Tag Manager** ke dalam Shoppego iaitu: -&#x20;

1. Daftar **Google Tag Manager**
2. Dapatkan dan simpan **GTM ID**
3. Masukkan **GTM ID** ke dalam Shoppego

## **Daftar Google Tag Manager**

1. **Pergi ke link** berikut <https://tagmanager.google.com/> dan **daftar menggunakan gmail anda** adalah langkah paling mudah.&#x20;

{% hint style="info" %}
\*\*<mark style="color:red;">**Perhatian**</mark>: Sekiranya anda menggunakan **Google Chrome** dan sedang log masuk ke dalam email anda, ianya akan automatik mendaftar dan dibawa ke halaman **Dashboard GTM** seperti gambar di bawah.&#x20;
{% endhint %}

![](../../../../.gitbook/assets/-MBcTc8iK2SrsHUq5N6c.png)

2. Klik butang **Create Account**<br>
3. **Masukkan maklumat yang diminta** pada ruangan yang telah disediakan. \
   **Biarkan** kotak **Share data anonymously with Google and others** menjadi <mark style="color:red;">**kosong**</mark>.
4. Pada bahagian **target platform klik** pada **Web**.<br>
5. Klik butang **Create** dan accept policy selepas itu klik butang **Create**.&#x20;

![](../../../../.gitbook/assets/-MBcToz2iVPuhfUzoP1f.png)

6. Seterusnya paparan seperti di bawah akan keluar&#x20;

![](../../../../.gitbook/assets/-MBcUDewgsNa36HC1OQt.png)

## **Dapatkan dan simpan GTM ID**

Pada ruangan kotak pertama anda akan lihat ID anda seperti yang telah di highlight di bawah yang bermula dengan **GTM-xxxxx**

{% hint style="info" %}
\*\*<mark style="color:red;">**Perhatian**</mark>: Simpan ID tersebut termasuk perkataan **GTM**.
{% endhint %}

![](../../../../.gitbook/assets/-MBcUUjdrkqeKyeYeZCt.png)

## **Penetapan di Shoppego**

1. Log masuk ke dashboard Shoppego pergi ke **Settings** -> **General** <https://my.shoppego.com/settings/general>
2. Masukkan **GTM ID** yang telah di simpan tadi di dalam ruangan **Google Tag Manager.**

![](../../../../.gitbook/assets/-MBcUqyIGigZygxMYjIm.png)

Klik butang **Save** dan kini website anda telah pun di link kan dengan **GTM**.&#x20;
