# Google Search Console

{% hint style="info" %}
Untuk membenarkan website kita **mendapat ranking** di dalam **enjin carian Google**, website kita perlu di submit kepada Google supaya mereka tahu tentang kewujudan website kita.&#x20;
{% endhint %}

Terdapat pelbagai cara untuk lakukan perkara ini antaranya ialah:-&#x20;

1. Menggunakan **HTML tag**
2. Menggunakan **Google Tag Manager**
3. Menggunakan **Google Analytic**
4. Menggunakan **DNS**&#x20;

{% hint style="success" %}
Cara yang paling **mudah dan pantas** adalah dengan menggunakan **HTML tag** kerana hanya perlu masukkan code yang diberikan sahaja.&#x20;
{% endhint %}

Pastikan anda **log masuk ke Gmail akaun anda** terlebih dahulu untuk menggunakan **Search Console**. Cara terbaik adalah menggunakan **browser Google Chrome** kerana semua telah automatik log masuk.&#x20;

## **Cara 1: Menggunakan HTML tag**

1. Pergi ke link berikut : <https://search.google.com/search-console/welcome>&#x20;

![](../../../../.gitbook/assets/-MBcJKSY2MdsDolqfsNG.png)

2. Paparan akan keluar seperti di atas.&#x20;
3. Jika anda menggunakan domain sendiri masukkan **nama domain anda di tab Domain**&#x20;
4. Jika anda menggunakan subdomain dari Shoppego contohnya **kedaisaya.myshoppegram.com** boleh masukkan pada **sebelah kanan tab** iaitu di **bahagian URL prefix.**  Dalam contoh ini akan menggunakan URL prefix.&#x20;
5. Pastikan terdapat **https\://** dan diikuti dengan **domain atau subdomain** anda.&#x20;

![](../../../../.gitbook/assets/-MX1KQUWmYGEB2m09zEi.jpg)

6. Klik butang **CONTINUE.**

![](../../../../.gitbook/assets/-MBcLFlrPycga97qOLJo.png)

7. Klik pada **HTML tag**&#x20;

![](../../../../.gitbook/assets/-MBcLTKARfjn9Kn9CrhZ.png)

8. Klik butang **COPY.**  Jangan tutup Google Search Console ini. Buka tab baru untuk log masuk ke dashboard Shoppego anda.&#x20;

## **Penetapan code tersebut di Shoppego**

1. Log masuk ke dashboard Shoppego anda pergi pada **Online Store** dan klik pada **Customize.**

![](../../../../.gitbook/assets/-MKJVYhXmIPoe0sHqhRL.png)

2. Pada bahagian halaman tersebut , anda boleh pergi ke bahagian **Other settings** dan masukkan code yang anda baru dapatkan diruangan **Custom meta.** Seterusnya klik butang **Save.**

![](../../../../.gitbook/assets/Xoo1QViH4v9oK9G08GoN.jpg)

3. Setelah selesai anda perlu pergi semula pada halaman **Google Search Console** sebentar tadi.

![](../../../../.gitbook/assets/-MBcMU4Ta_HOl9YsPZrz.png)

4. Klik butang **Verify**&#x20;

![](../../../../.gitbook/assets/-MBcMbp0dU4ycy_mdfsy.png)

5. Pastikan keluar paparan seperti gambar diatas menyatakan **Ownership verified**. Klik butang **Done**

Kini website anda telah berjaya di submit ke google Search console untuk mendapatkan ranking di enjin carian Google.

## Semak Status Submission

1. Klik pada perkataan **Search property.** Akan keluar paparan seperti dibawah :

![](../../../../.gitbook/assets/-MBcMr59ZtNuAGNAu1nv.png)

2. Klik pada nama domain yang telah anda submit tadi.&#x20;
3. Pada ruangan search bar di bahagian atas masukkan nama **URL** anda dengan **https\://**
4. Tekan butang **ENTER** pada keyboard anda

![](../../../../.gitbook/assets/-MBcN0GIf29C8EEQVE3T.png)

## Penetapan Sitemap

Sitemap ini dapat memudahkan Google untuk crawl website anda bagi sebarang update terkini yang telah dibuat oleh anda pada pages/website anda.

Untuk penetapan anda boleh rujuk tutorial dibawah :

1. Pada dashboard Google Search Console, anda boleh klik pada butang **Sitemaps**

![](../../../../.gitbook/assets/-Md_9NCbp_AXm8GKDLoB.jpg)

2. Seterusnya, anda bole masukkan link sitemap anda pada ruangan yang disediakan seperti dibawah.&#x20;
3. Anda hanya perlu masukkan text **sitemap.xml** pada ruangan yang telah disediakan. Setelah selesai anda boleh klik **Submit**

![](../../../../.gitbook/assets/-Md_BI_f9a9JdTv7EpMR.jpg)

4. Setelah selesai anda boleh refresh page tersebut dan pastikan status submission anda Success.

![](../../../../.gitbook/assets/-Md_CQycJyB39YCApOgQ.png)
