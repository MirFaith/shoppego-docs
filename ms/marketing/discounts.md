# Discounts

**Discounts** adalah salah satu features dimana anda boleh membuat penetapan untuk kod voucher yang boleh digunakan oleh pelanggan anda untuk mendapatkan promo yang anda sudah sediakan.

{% hint style="success" %}
Fungsi ini hanya tersedia untuk **plan&#x20;**<mark style="color:red;">**Premium**</mark> dan <mark style="color:red;">**Ultimate**</mark> sahaja.\*
{% endhint %}

Untuk membuat penetapan diskaun kod, anda boleh ikut tutorial ini :

1\. Login ke Dashboard Shoppego anda.

![](../../.gitbook/assets/lCN7aw3FznaFFoOAyya2.jpg)

2\. Klik pada tab **Marketing**

![](../../.gitbook/assets/tjKWI2MSLkmmGXAL8lpP.jpg)

3\. Klik pada tab **Discounts**&#x20;

![](../../.gitbook/assets/VOhhKRqxuqG8UOzKnShL.png)

4\. Klik pada button **Create discount**

![](../../.gitbook/assets/R1EDG5Fo0zKYWh3wV792.png)

Didalam Shoppego ada **2 jenis diskaun** yang anda boleh cipta:

#### Manual diskaun

Jenis diskaun ini memerlukan pelanggan anda untuk masukkan diskaun kod yang anda sudah cipta itu didalam halaman checkout website anda. Jika pelanggan tidak dapat memenuhi kriteria diskaun tersebut, pelanggan tersebut akan dapat lihat mesej ralat di halaman checkout tersebut.

#### Automatic diskaun

Jenis diskaun ini membolehkan pelanggan **secara automatik mendapatkan promo diskaun** anda t**anpa memerlukan mereka memasukkan kod diskaun** tersebut di halaman checkout website anda. Sekiranya, pelanggan tidak memenuhi kriteria diskaun tersebut, pelanggan tidak akan dapat lihat apa2 mesej ralat di halaman checkout. **Fungsi ini. hanya tersedia untuk langganan Ultimate sahaja**.&#x20;
