# Fungsi pakej

Setiap [Pakej Langganan Shoppego](https://shoppego.com/pricing) menyediakan pelbagai fungsi kepada pengguna.&#x20;

Pakej Langganan Shoppego tidak mempunyai pakej khusus untuk sesuatu perniagaan kerana platform ini direka khas untuk apa jua jenis perniagaan anda.&#x20;

Antara **jenis perniagaan** yang biasa digunakan oleh pelanggan Shoppego adalah seperti&#x20;

* Produk Digital
* Makanan & Minuman
* Fashion seperti pakaian, tudung dsb.&#x20;

{% hint style="info" %}
Jika anda mempunyai sebarang soalan berkaitan dengan harga Pakej Langganan Commerce, anda boleh emailkan pertanyaan tersebut kepada kami di **<hello@shoppego.com>**. Team kami akan membantu dalam menjawab segala persoalan anda.
{% endhint %}
