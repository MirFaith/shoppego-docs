# Variants

## Penetapan varians

{% hint style="info" %}
\*\*<mark style="color:red;">**Perhatian**</mark>: Penetapan **maksimum bagi Varians** adalah **100 sahaja.**
{% endhint %}

{% content-ref url="variants/variants-setup.md" %}
[Variants Setup](variants/variants-setup.md)
{% endcontent-ref %}

{% content-ref url="variants/variants-imej.md" %}
[Variants Imej](variants/variants-imej.md)
{% endcontent-ref %}

**Product variants** digunakan untuk membuat **lebih dari satu pilihan** bagi **produk yang sama**:&#x20;

Sebagai contoh :

* **Produk baju** yang mempunyai **banyak saiz**.
* **Produk kayu** mempunyai banyak **ukuran**.

Variants juga boleh digunakan sebagai pilihan untuk membuat **produk kombo.**&#x20;

{% content-ref url="variants/variants-for-combo-promo.md" %}
[Variants for Combo Promo](variants/variants-for-combo-promo.md)
{% endcontent-ref %}

{% hint style="info" %}
\*\*<mark style="color:red;">**Perhatian**</mark>: Sebelum anda meneruskan tutorial ini pastikan anda telah **menambahkan produk** anda terlebih dahulu dan **Save** produk tersebut.&#x20;
{% endhint %}

{% hint style="info" %}
\*\*<mark style="color:red;">**Perhatian**</mark>: Pastikan anda **telah lakukan penambahan Options(Button/Dropdown/Swatch) pada produk anda terlebih dahulu**, jika anda **ingin lakukan penambahan variants** pada produk anda.
{% endhint %}

{% content-ref url="options.md" %}
[Options](options.md)
{% endcontent-ref %}

## **Akses Variants**

1. Log masuk ke Dashboard Commerce anda.

![](../../.gitbook/assets/lCN7aw3FznaFFoOAyya2.jpg)

2. Klik pada **Products**

![](../../.gitbook/assets/HgFrkw3BSgfEtSw9Sp2u.png)

3. Klik pada **All Products**

![](../../.gitbook/assets/qPOXNTIV0Ng01bxriWyx.jpg)

4. Klik pada nama produk yang anda ingin tambah/ubah Variants.

{% hint style="info" %}
**Untuk penambahan variants, pastikan anda telah lakukan penambahan Options(Button/Dropdown/Swatch) terlebih dahulu pada produk tersebut.**
{% endhint %}

![](../../.gitbook/assets/Y8wIVUWiSDlAWJiE3SDf.png)

5. Seterusnya klik pada tab **Variants**&#x20;

![](../../.gitbook/assets/Ry0TzkcLn6to51Du1lgT.png)

Secara default untuk setiap produk akan keluar **Default** variant.&#x20;

![](../../.gitbook/assets/d0yOirROrgD2tK56vhmo.jpg)

## Inventori

### 1 : View Inventory Logs

{% hint style="info" %}
\*\*<mark style="color:red;">**Perhatian**</mark> : **Bahagian SKU** adalah untuk **memantau data bagi produk anda** dan <mark style="color:red;">**bukan**</mark>**&#x20;untuk kemaskini stok.**
{% endhint %}

Pada bahagian ini anda dapat melihat perubahan atau jejak kuantiti yang dilakukan pada bahagian stok produk.\
\
1\. Klik pada **View inventory logs**.

![](../../.gitbook/assets/woEkykkWCZkh7SCjw5rk.png)

<br>

2. Pada ruangan ini akan tercatat segala perubahan yang dilakukan pada bahagian quantity stock produk.

![](../../.gitbook/assets/mVqSfbt6ljNF5O79En1N.png)

<table><thead><tr><th width="155">Tajuk</th><th>Penerangan</th></tr></thead><tbody><tr><td><strong>Alamat</strong> </td><td>Anda boleh menukar alamat pada ruangan ini untuk melihat perubahan logs berdasarkan lokasi.</td></tr><tr><td><strong>Date</strong> </td><td>Tarikh setiap perubahan dilakukan.</td></tr><tr><td><strong>Activity</strong> </td><td>Merujuk pada perkara yang anda lakukan semasa mengubah kuantiti stok</td></tr><tr><td><strong>Adjusted by</strong></td><td>Merujuk kepada penama/siapa yang melakukan perubahan kepada stock tersebut.</td></tr><tr><td><strong>Available</strong> </td><td>Merujuk kepada nilai terbaru stock </td></tr></tbody></table>

### 2 : Stok Produk

1. Untuk **lakukan penambahan stok produk**, anda perlu masukkan kedalam ruang yang telah disediakan. Anda hanya perlu tekan dropdown itu sahaja.

<figure><img src="../../.gitbook/assets/wdOygixkmnD7w13SxKh8.jpg" alt=""><figcaption></figcaption></figure>

2. Selepas itu, anda boleh **pilih sebab atau maklumat yang berkaitan** dengan perubahan stok produk anda.

<figure><img src="../../.gitbook/assets/Yu8F9hTI0aZtbWbDX3aQ.jpg" alt=""><figcaption></figcaption></figure>

3. Anda akan lihat nilai kemaskini terbaru bagi stok produk anda.

{% hint style="info" %}
Jika butang **Manage Stock&#x20;**<mark style="color:red;">**tidak**</mark>**&#x20;dihidupkan**, produk anda akan dikira mempunyai **stok tanpa had (**<mark style="color:blue;">**unlimited**</mark>**).**
{% endhint %}

<figure><img src="../../.gitbook/assets/FCPnWMw1Hexr5r6teGsR.png" alt=""><figcaption></figcaption></figure>

4. Jika anda menekan butang **View Inventory Logs**, anda akan lihat senarai maklumat bagi perubahan stok produk anda.

<figure><img src="../../.gitbook/assets/U4SfKlNeluUWCmDESHTU.jpg" alt=""><figcaption></figcaption></figure>
