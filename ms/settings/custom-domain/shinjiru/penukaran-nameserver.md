# Penukaran Nameserver

1. Untuk penukaran Nameserver dalam Shinjiru, anda boleh tekan pada **dropdown Domains** dan **klik My Domains**.

<figure><img src="../../../../.gitbook/assets/9THoqGTJozTzrwFQD5rz.jpg" alt=""><figcaption></figcaption></figure>

2. Kemudian, pastikan anda **tandakan pada domain anda (1)** dan **tekan pada Manage Nameservers (2).**

<figure><img src="../../../../.gitbook/assets/XKUvOWhiZYvn9JaoCRoT.jpg" alt=""><figcaption></figcaption></figure>

3. Klik pada tab "**Advanced Settings**".&#x20;
4. Pilih "**Use custom nameservers**" dari senarai pilihan.&#x20;
5. Masukkan nameservers Cloudflare yang anda dapat di tab "**DNS**" akaun Cloudflare anda di ruang yang sesuai. Anda perlu memasukkan **sekurang-kurangnya dua nameservers**.&#x20;
6. Klik pada butang "**Save Changes**" untuk **mengemas kini nameservers** untuk domain anda.&#x20;

{% hint style="info" %}
Setelah anda menyimpan perubahan, ia mungkin **mengambil masa sehingga 24-48 jam** untuk nameservers baru propagate ke seluruh internet.&#x20;
{% endhint %}

{% hint style="danger" %}
Semasa ini, laman web anda **mungkin mengalami sedikit masalah,** oleh itu penting untuk merancang dengan sewajarnya.&#x20;
{% endhint %}

{% hint style="info" %}
Sekiranya **anda mengalami sebarang isu** untuk penukaran nameserver ini, anda boleh **hubungi pihak domain provider** untuk mereka bantu anda dalam lakukan penetapan ini.
{% endhint %}

{% hint style="success" %}
Setelah propagation selesai, **domain anda** akan **menggunakan nameservers Cloudflare** dan anda akan dapat **menguruskan tetapan DNS anda melalui dashboard Cloudflare**.
{% endhint %}
