# Brevo

Untuk buat penetapan **Brevo**, anda perlu dapatkan **API Key** dari **Brevo** dan **masukkan key** yang telah anda dapatkan masuk kedalam sistem Shoppego.

## Log masuk akaun Brevo

1. Anda boleh log masuk kedalam akaun Brevo [<mark style="color:blue;">**di sini**</mark>](https://login.brevo.com/) atau pada link ini: <https://login.brevo.com/>

<figure><img src="../../../.gitbook/assets/e2GOuF3oQdluWYcEdpZh.jpg" alt=""><figcaption></figcaption></figure>

## Dapatkan API key Brevo

1. Anda akan dibawa ke halaman **Dashboard Brevo**, anda perlu **tekan pada bahagian atas kanan** dan **dropdown** yang ada disitu.

<figure><img src="../../../.gitbook/assets/GhL24D3PYZHnmu22rhJk.jpg" alt=""><figcaption></figcaption></figure>

2. Anda boleh tekan pada **dropdown profile menu dan pilih Settings**

<figure><img src="../../../.gitbook/assets/rRpt5Rvrtdk1rfcQ90eh.jpg" alt=""><figcaption></figcaption></figure>

2. Setelah itu, anda boleh **tekan** pada **SMTP & API**

<figure><img src="../../../.gitbook/assets/698ZJbk6h1nSchy8qOHH.jpg" alt=""><figcaption></figcaption></figure>

4. Seterusnya, anda boleh klik pada **API keys & MCP**

<figure><img src="../../../.gitbook/assets/kh9zVo9DPtzhEUqsmvEk.jpg" alt=""><figcaption></figcaption></figure>

5. Setelah itu, anda boleh klik pada **Generate a new API Key**

<figure><img src="../../../.gitbook/assets/r88PVIrhk9NXiRTAoUht.jpg" alt=""><figcaption></figcaption></figure>

6. Nanti anda akan **diminta untuk masukkan nama API key** anda itu dan anda boleh klik **Generate**

<figure><img src="../../../.gitbook/assets/UkB2UgNqEvvhKIDiZ2lu.jpg" alt=""><figcaption></figcaption></figure>

7. Setelah selesai, anda akan dapat lihat dan **copy API key** anda itu untuk digunakan bagi proses integration di platform Shoppego nanti

<figure><img src="../../../.gitbook/assets/lUls7Nv9XvvAkW5qXx1Y.jpg" alt=""><figcaption></figcaption></figure>

## Dapatkan List ID(Optional)

Sekiranya anda tidak lakukan penetapan ini, maklumat pelanggan anda yang akan dibawa masuk itu tidak akan berada didalam mana-mana list.

1. Log masuk dashboard Brevo

<figure><img src="../../../.gitbook/assets/e2GOuF3oQdluWYcEdpZh.jpg" alt=""><figcaption></figcaption></figure>

2. Klik pada menu **CRM**

<figure><img src="../../../.gitbook/assets/Lzznb1s9pw28FVbLxG4h.jpg" alt=""><figcaption></figcaption></figure>

3. Klik pada menu **Lists**

<figure><img src="../../../.gitbook/assets/tdQ8eET7VLRYN6jS5ksb.jpg" alt=""><figcaption></figcaption></figure>

4. Nanti anda akan dapat lihat maklumat "**List ID**" untuk list yang anda ingin gunakan.

<figure><img src="../../../.gitbook/assets/wTruqvXGJI4cZi0I29ke.jpg" alt=""><figcaption></figcaption></figure>

## Penetapan di Shoppego

1. Pada **Dashboard Overview**, anda boleh pergi ke **Settings**.

<figure><img src="../../../.gitbook/assets/VsK9zs6aZtUfKK1hcCiM.jpg" alt=""><figcaption></figcaption></figure>

2. Selepas itu, anda boleh tekan pada **Email Marketing Provider**.

<figure><img src="../../../.gitbook/assets/G7jjXYelY1uP9ZamRoMj.jpg" alt=""><figcaption></figcaption></figure>

3. Pada halaman ini, anda akan perlu tekan butang **Activate** untuk **mengaktifkan Brevo** dan tekan **Edit**.

<figure><img src="../../../.gitbook/assets/98ol7Evq70YE9P5xzPw3.jpg" alt=""><figcaption></figcaption></figure>

4. Anda perlu masukkan **API key** yang anda telah dapat dari **Brevo** kedalam ruang yang disediakan. Anda juga boleh letakkan **List ID**.&#x20;

{% hint style="info" %}
\*\*<mark style="color:red;">**Perhatian**</mark> :&#x20;

* **List ID** - Digunakan untuk meletakkan pelanggan yang berdaftar kedalam kumpulan yang anda mahukan.&#x20;
  {% endhint %}

5. Pastikan anda hidupkan toggle **Enable** untuk menggunakan **Brevo**

<figure><img src="../../../.gitbook/assets/uoDecMaz0Gb3ESfLyfuR.jpg" alt=""><figcaption></figcaption></figure>

<mark style="color:blue;">**Tahniah**</mark>! Penetapan **Brevo** anda telahpun berjaya.

### Sync Maklumat pelanggan Shoppego Dengan Brevo List

**Sekiranya anda ingin lakukan penetapan Sync List Brevo anda dengan maklumat pelanggan anda dari platform Shoppego, anda perlu pastikan anda telah lakukan penetapan "**[**Deactivated Blocking Unauthorized IP Address**](brevo.md#deactivated-blocking-unauthorized-ip-address)**" terlebih dahulu.**

Untuk lakukan sync maklumat, anda hanya perlu klik pada butang **Sync All Customers/Sync**

<figure><img src="../../../.gitbook/assets/AtrJQEHnOcl8dZK8lmOv.jpg" alt=""><figcaption></figcaption></figure>
