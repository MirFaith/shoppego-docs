# COD payment

## Penetapan Global Rates

{% hint style="info" %} <mark style="color:red;">**Perhatian**</mark>: Sebelum anda meneruskan tutorial ini **pastikan pada setiap produk anda** adalah dalam keadaan **Global Rates** .&#x20;
{% endhint %}

Anda boleh pergi ke:&#x20;

**Dashboard Overview -> Produk -> Pilih Produk Anda -> Edit -> Shipping -> Global Rates (On) / Requires Shipping or Pickup (On).**&#x20;

## Bahagian 1 Setup COD Payment

1\. Log masuk ke Dashboard Shoppego -> **Settings**

![](../../../.gitbook/assets/VsK9zs6aZtUfKK1hcCiM.jpg)

2\. Di halaman Settings, Klik **Payment Options**

![](../../../.gitbook/assets/CA5qmbxGnMXdjUXh5W4M.jpg)

3\. Pada pilihan **Cash On Delivery (COD)**, klik **Activate/Edit**

![](../../../.gitbook/assets/lmAZAGq8oaxsMRQ7lQFq.jpg)

4\. Pastikan paparan seperti gambar dibawah. Masukkan **maklumat** di dalam ruang yang telah disediakan.

![](../../../.gitbook/assets/5SuFBWXFj0NgOU2sBIc2.jpg)

* Isikan maklumat berbentuk **arahan, peringatan atau informasi** pada borang “**Additional Details**”.
* Maklumat yang **diisi pada bahagian ini** akan dipaparkan pada “**Checkout Page**” ketika pengguna hendak membuat pembelian.
* Sebagai contoh “**Barang sampai baru bayar**”.

Jadi maklumat ini akan dipaparkan sebelum complete order.

![](../../../.gitbook/assets/-MBg0elhGk8HFdiYw_d6.png)

Borang "**Payment Instruction**" ini akan dipaparkan pada “**Thank You**” page iaitu selepas pengguna klik butang “**complete order**”.

![](../../../.gitbook/assets/-MBg1DKfVbnZJybAemNp.png)

{% hint style="info" %} <mark style="color:red;">**Perhatian**</mark> : Pastikan kotak “**Enable**” ditanda seperti gambar di bawah dan terus tekan butang “**Save**”
{% endhint %}
