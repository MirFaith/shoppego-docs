Di Shoppego, anda boleh hubungkan website anda dengan sistem Whatsapp Provider seperti:

{% content-ref url="whatsapp-providers/onsend.md" %}
[Onsend](whatsapp-providers/onsend.md)
{% endcontent-ref %}

{% content-ref url="whatsapp-providers/wabot.md" %}
[Wabot](whatsapp-providers/wabot.md)
{% endcontent-ref %}

Sebelum memulakan penetapan berikut, anda perlu membuat penetapan notification Whatsapp message yang akan dihantar terlebih dahulu.

{% hint style="info" %}

* Fungsi ini hanya available untuk **plan&#x20;**<mark style="color:red;">**Premium**</mark> dan <mark style="color:red;">**Ultimate**</mark> sahaj&#x61;**.**
* Whatsapp notifications yang boleh dihantar kepada pelanggan hanyalah <mark style="color:red;">**Order confirmation, Order shipped, Order review, Order packed**</mark> dan <mark style="color:red;">**Order ready for pickup**</mark> sahaja buat masa sekarang.
  {% endhint %}

## **Penetapan di Shoppego**

1\. Log masuk ke akaun Shoppego anda.

![](../../.gitbook/assets/lCN7aw3FznaFFoOAyya2.jpg)

2\. Klik pada tab **Settings**

![](../../.gitbook/assets/kpzKJV4N5OQiCaTGUeRo.jpg)

3\. Klik pada tab **Notifications**

![](../../.gitbook/assets/-MMTSrPUzxtd_uQjJuXz.png)

4\. Klik butang **Edit** pada tab Order Confirmation

![](../../.gitbook/assets/-MMTTHn_Hyktv6-TGxhv.png)

5\. Klik pada tab **Whatsapp**

![](../../.gitbook/assets/6tbEJEYoLt2dkOh7KCfi.jpg)

6\. Pada ruangan **Content**, anda boleh masukkan text/message yang anda ingin hantar kepada pelanggan setelah mereka membuat pembayaran diwebsite anda.&#x20;

![](../../.gitbook/assets/7n8RF5tcCGEKNUvLRaKA.png)

7\. Setelah selesai, anda boleh klik **Save**

![](../../.gitbook/assets/PCogSJ9nfsxU3ZRhkGyR.jpg)

8\. Anda perlu pastikan Order Confirmation tersebut berada dalam keadaan **Enable**. ( Pastikan ia bewarna biru )

![](../../.gitbook/assets/2AAePobBEtGk7kzweqtT.jpg)

Setelah selesai, anda boleh membuat penetapan Whatsapp notification yang lain.
